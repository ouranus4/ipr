# ИПР · трекер

Личный трекер индивидуального плана развития: стадии, недельные нормы, деньги, система «движа».

Открыть: **index.html** — файлом с диска или по ссылке GitHub Pages. Зависимостей нет, сборка не нужна, работает офлайн.

## Приватность

В этом репозитории **нет персональных данных**. Ни дат рождения, ни доходов, ни имён клиентов, ни заметок.

Всё, что вводится в трекере, хранится только в `localStorage` того браузера, где ты это ввела. Наружу не уходит никуда: ни на сервер, ни в репозиторий, ни в аналитику — её тут просто нет.

Перенести данные между телефоном и компьютером: **Ещё → Выгрузить** (получится JSON-файл), затем на другом устройстве **Ещё → Загрузить**. Файл держи у себя, в репозиторий его не коммить.

Так как данные лежат в браузере, они пропадут при очистке данных сайта, в приватном окне и при смене браузера. Выгружай файл раз в неделю.

## Что внутри

- **Сегодня** — ключевое действие месяца, дневные отметки, норма недели, большие события
- **Движ** — колода из 100 конкретных дел по 10 категориям: еда, вещь, место, человек, знание, тело, руки, голос, соревнование, красота. Плюс свой журнал и разброс по категориям
- **Деньги** — цель месяца, разделение на повторяющийся и разовый доход, журнал поступлений, динамика по месяцам
- **Карта** — четыре рождения как стадии прогресса с критериями
- **Ещё** — щиты (стрики наоборот: дни, когда риск не случился), ачивки, настройки, выгрузка данных

Нормы недельные, а не дневные: один провалённый день ничего не ломает.

## Файлы

```
index.html          разметка и навигация
assets/styles.css   тёмная и светлая темы, мобильный layout
assets/data.js      стадии, колода, ачивки, уровни — без персональных данных
assets/app.js       состояние, подсчёт XP, экраны, выгрузка
```

## GitHub Pages

Settings → Pages → Source: `main`, папка `/` (или `/docs`, если переложишь туда). Через минуту сайт будет доступен по ссылке, её можно добавить на домашний экран телефона как иконку.
